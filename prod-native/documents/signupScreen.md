# signupScreen

**Files:** `signupScreen.tsx` 

## signupScreen: 
- `useState`: to track email and password inputs.
- `secureEntry(boolean)`: for password UI state toggling.
- `navigation.replace("TIMER")`: instead of simple map. Users after success login leads to Timer page
- `handleGoback` function: go back 
- `handleLogin`: go to login
- `keyboardType= "phone-pad"` : to show padphone to user
- `handleSignup`: to validate email, password and phone
